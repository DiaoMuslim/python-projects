# Todo List

## Description
A simple Pyton Todo List application

## Features 
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Simple and easy-to-use menu

## Technologies Used
- Python

## How to Run
1. Open the terminal.
2. Navigate to the project folder
3. Run:

   bash
python todo_List

- Lists
-Loops
-Conditionan statements
- User input
- Menu-driven programs
