# Unit Converter

## Description
A Python application for converting different units of measurement.

## Features
- meters to Kilometers
- milometers to Meters
- Grams to Kilometers
- Celsius to Fahrenheit
- Fahrenheit to Celsius

  ## Technologies used
  - Python

 ## How to Run
    bash
python unit_converter.py

## Skills Demonstrated
- Mathematical calculations
- Conditional staatements
- User input
- Menu-driven programming
